🧩 收進 Figma 的結構建議

照既有元件的慣例（像 Pagination Item、Table Cell），做「單顆 Step Item」的 master， 整條 Stepper 在文件頁用 auto-layout 組合示範，不把整條做成一個元件（步數會變動）。

元件 Property 說明
Step Item [master] State（VARIANT）
Upcoming / Current / Done		 3 個 variant。Done 自動顯示打勾隱藏數字
Show Label（BOOLEAN） 預設 true。關掉就是純圓點用法
Step Line [master] State（VARIANT）
Default / Done		 獨立元件，這樣線的顏色可以獨立切換
（第 2 步進行中時，第 1 條線是 done、第 2 條還沒）
文字標籤不做成 TEXT property。 Figma 的限制：同一個 TEXT property 綁到多個 variant 上會強制共用同一個預設值， 會害三個狀態全變成同一行字。跟 Badge、Checkbox 一樣保留各 variant 獨立、可雙擊編輯。
